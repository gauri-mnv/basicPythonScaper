# PYSCAPER

A Python web scraping project using:

- Playwright
- Selenium
- Firefox
- XPath/CSS Selectors

This project is used for learning and practicing modern web scraping techniques including:

- Browser automation
- Dynamic website scraping
- PDF extraction
- XPath handling
- Waiting strategies
- Search automation

---

# Features

- Automated browser interaction
- Search form handling
- Dynamic content scraping
- PDF link extraction
- Screenshot capture
- XPath and CSS selector support
- Headless and visible browser modes
